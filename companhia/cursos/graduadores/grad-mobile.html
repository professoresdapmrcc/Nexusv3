CENTRAL DE APLICAÇÕES DE MOBILE

Dispõe-se nesta página o acesso à ferramenta de aplicação para mobiles.

ORIENTAÇÕES
  • ➤ A execução da graduação deve ocorrer, inevitavelmente, na sala de aplicação destinada aos graduadores. Caso esta esteja ocupada, é possível usar a sala dos estagiários;
  • ➤ Não é permitido, em hipótese alguma, pular qualquer parte do script;
  • ➤ Atente-se ao script e às possíveis dúvidas do professor para esclarecê-las de forma correta.
  • ➤ Caso o professor caia durante a aplicação, printe o perfil dele offline com o histórico aberto ao lado, contendo balões visíveis de ambos envolvidos e, por fim, poste no formulário dos graduadores;
  • ➤ Lembre-se de postar a graduação no formulário ao final.

COMO UTILIZAR A FERRAMENTA?

➤ É recomendável utilizar a tela na horizontal;

➤ No campo "Selecione a aula", você deve escolher a aula desejada para ter acesso ao script;

➤ No campo 'Opções', estão disponíveis os trechos de cada parte das aulas para acesso aos scripts;

➤ Para copiar, basta clicar no botão "Copiar";

➤ Na opção "Postagem", estão disponíveis todos os links, como formulários de postagem, correção e o system para postagem dos cursos obrigatórios;

➤ Em casos de problemas com a ferramenta consultar um conselheiro+.
